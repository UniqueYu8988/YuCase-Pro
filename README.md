# 👑 YuCase Pro (v1.0) 💍🚀💖

**YuCase Pro** 是专为非计算机背景医疗工作者设计的终极病案极速填报引擎。它融合了现代桌面端架构、深度词典映射与物理级数据拦截协议，旨在将繁琐的 241 项数据填报缩减至“双击 F8/F9”的丝滑体验。

## 🌟 核心特性 (Key Features)

- **上帝之手 (Global F8/F9)**：支持非聚焦状态下的全局快捷键。一键唤醒，一键击发。
- **物理级拦截 (Hard Override)**：强制付款方式锁定 `02`，亲属关系智能补全，确保零误差产出。
- **进程级隔离 (Lifecycle isolation)**：采用一次性 Python 进程架构，确保每次填报都是绝对纯净的单兵作战。
- **皇家视觉 (Royal Standard)**：重度玻璃拟态设计，皇家紫呼吸灯反馈，极致的极客审美。

## 🚀 快速上手

1. **上膛 (Armed)**：按下 **F8**（全局生效）拉起 Python 引擎。
2. **击发 (Fire)**：按下 **F9**（全局生效）开始 250 项极速自动填报。
3. **强杀 (Kill)**：填报中按下 **F9** 可瞬间物理打断进程。

## 🛠️ 技术底座

- **Frontend**: React + Vite + Tailwind CSS (Royal Custom)
- **Backend**: Python 3.x (Regex Scalpel + PyAutoGUI)
- **Wrapper**: Electron (IPC 影子监听)
