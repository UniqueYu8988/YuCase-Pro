## ✨ 灵魂设计要点 (Design Philosophy)

### 1. 呼吸感交互 (Invisible UI)

在 YuCase Pro 的设计语言中，**“少即是多”**是绝对的铁律：

- **隐藏式标题栏**：窗口控制按钮默认隐藏，仅在鼠标悬停时平滑显现，将界面纯净度推向极致。
- **猫咪水印彩蛋**：主界面深处的“Always here for Yu”不仅是品牌标识，更是作为视觉锚点，缓解工作时的压力，赋予冰冷代码以人的情感。

### 2. 皇家视觉标准 (Royal Glassmorphism)

- **40px 超深度模糊**：容器采用极致的毛玻璃效果 (`backdrop-filter: blur(40px)`)，配合 `1px` 的极细高光边框，营造出深邃且高级的悬浮感。
- **皇家紫 (#a855f7) 呼吸灯**：所有击发状态、按钮高亮均使用皇家紫作为强调色，配合 0.3s 的线性过渡，操作反馈如同心跳般自然。

### 3. 数据可视化雷达 (Color-Coded Intelligence)

我们将枯燥的数据报错转化为直观的视觉反馈：

- **红区 (Fatal)**：字段缺失，物理拦截。
- **黄区 (Warning)**：语义模糊，提醒核对。
- **橙区 (Audit)**：财务误差，高优先级拦截。
- **绿区 (Safe)**：常规修复，静默运行。

## 🧠 核心技术底座 (Engine Power)

- **上帝之手 (Global Hotkeys)**：F8 全局上膛，F9 战术击发。实现“跨维监听”，无需聚焦窗口即可掌控全局。
- **进程级物理隔离**：每次填报拉起全新影子进程，执行即销毁，确保系统永远处于初始的巅峰状态。
- **语义洗碗机**：深度针对医疗词典的正则引擎，自动修正亲属关系与财务格式。
